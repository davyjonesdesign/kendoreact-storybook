# Wheels UI Storybook (KendoReact Staging Ground)

This repo serves as a staging ground for developing and refining the **Wheels UI design system** using KendoReact components and Storybook.

It provides an isolated environment for:

- Testing KendoReact components with custom theming via ThemeBuilder
- Iterating on Wheels UI styles and tokens
- Visualizing components in context through Storybook

## Getting Started

To launch the Storybook instance:

```bash
npm install
npm run storybook
